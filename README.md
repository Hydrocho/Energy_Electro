# 빛의 신호 · 30초 발전 챌린지

안드로이드 패드에서 자석을 좌우로 드래그하여 짧고 긴 빛 신호를 보내는 게임입니다. 음높이 조절과 소리는 없으며, 외부 라이브러리나 실행 전 빌드가 필요 없습니다.

## 실행

`light-rhythm.html` 하나를 브라우저로 열면 됩니다. 기존 파일 이름을 유지했으므로 열려 있는 페이지를 새로고침하세요. 패드에서 로컬 HTML 열기를 제한하면 정적 웹 호스팅에 올려 같은 주소로 접속하세요.

개발용 원본은 `index.html`, `styles.css`, `engine.js`, `records.js`, `game.js`입니다. 수정 후 `node scripts/package.cjs`로 단일 배포 파일을 갱신할 수 있습니다. Node는 학생들의 실행에 필요하지 않습니다.

## 플레이

1. 하·중·상 난이도를 고르고 먼저 연습하거나 30초 도전을 시작합니다.
2. 오른쪽 신호 막대가 판정선에 닿으면 왼쪽 자석을 좌우로 계속 움직입니다.
3. 빈 구간에서는 멈춥니다. 손을 떼면 전구가 즉시 꺼집니다.
4. 신호 중 빛을 내면 가점, 빈 구간에서 빛을 내면 감점입니다. 신호를 놓치면 가점 없이 콤보가 끊깁니다. 점수는 0~10,000점입니다.
5. 정확한 속도나 밝기를 맞출 필요가 없고, 필요 이상 빨리 흔들어도 추가 점수는 없습니다. 방향 전환과 신호 경계에는 짧은 판정 여유가 있습니다.

하는 긴 신호와 넉넉한 쉼, 중은 짧고 긴 신호의 조합, 상은 빠른 신호 전환입니다. 같은 난이도끼리 점수를 비교하세요. PC에서는 마우스 또는 조작 영역에 초점을 둔 뒤 좌우 방향키를 사용합니다.

## 오늘의 기록

기기·브라우저의 localStorage에 현지 날짜 기준 오늘의 난이도별 최고 점수, 최고 콤보, 도전 횟수, 최근 10개 기록을 저장합니다. 온라인 순위나 전송은 없습니다. 날짜가 바뀌면 새 기록을 시작하고 중단한 판은 저장하지 않습니다. 저장이 차단되면 현재 화면에서만 유지됩니다.

점수 규칙이 바뀌었으므로 이전 음높이 게임의 기록과 섞지 않도록 별도 저장 키를 사용합니다. 이전 데이터를 삭제하지 않습니다.

## 학습 모형

자석과 코일의 상대 운동으로 유도 전류가 생기는 원리를 빛의 켜짐·꺼짐으로 단순화한 게임입니다. 실제 전구의 연속적인 밝기를 정밀하게 재현하는 모형은 아닙니다. 모스 부호처럼 짧고 긴 신호를 사용하지만 실제 문자 부호를 해독하는 게임은 아닙니다.

## 검증

`node --test tests/core.test.js tests/ui-state.test.js`

`node preview.cjs`로 PC의 http://127.0.0.1:4173 에서 미리 볼 수 있습니다. 이 주소는 학생 패드용 공유 주소가 아닙니다.

## 상 난이도 강화

하·중의 패턴과 판정은 유지합니다. 상은 28개 신호로 구성하며 첫 10초 적응, 다음 10초 연속 짧은 신호, 마지막 10초 긴 신호 속 짧은 쉼으로 진행합니다. 미리 보기는 2.8초이고 빈 구간 감점은 2배입니다. 최단 신호와 쉼은 약 0.3초이며 기존 방향 전환 여유는 유지합니다.

이전 상 기록은 기존 저장 공간에 보존하고, 강화된 상은 새 기록을 시작합니다. 오늘의 하·중 기록은 자동으로 이어집니다.
