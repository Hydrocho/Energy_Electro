# 빛의 신호 · 60초 발전 챌린지

light-rhythm.html 하나를 브라우저로 여세요. 설치나 빌드는 필요 없습니다. 파일 실행이 제한된 패드에서는 정적 웹 주소에 배포하세요.

## 단계와 조작

1단계 긴 신호, 2단계 짧고 긴 신호, 3단계 고속 전환, 4단계 불규칙 연속 신호, 5단계 초고속 신호입니다. 1~3단계는 이전 패턴을 두 번 이어서 60초로 구성합니다. 4·5단계는 더 촘촘한 신호와 각각 2.2초·1.7초 미리 보기를 사용합니다.

왼쪽 자석을 좌우로 움직여 오른쪽 막대가 판정선을 지날 때 빛을 내세요. 빈 구간에서 빛을 내면 감점됩니다. 손을 떼면 바로 꺼집니다. 3~5단계는 감점 2배입니다. 총점은 10,000점입니다.

## 생존 규칙

준비 시간을 제외한 플레이 20초부터 0.1초마다 누적 획득률을 판정합니다.
누적 획득률 = 감점을 반영한 현재 점수 / 지금까지 지나간 신호에서 얻을 수 있었던 최대 점수

- 70% 이상: 정상
- 60% 이상 70% 미만: 노트 화면 붉은 점멸. 70% 이상 회복 시 해제
- 60% 미만: 즉시 GAME OVER

판정은 반올림 전 비율을 사용합니다. 분모에는 미래 노트나 쉼이 포함되지 않습니다. 연습에는 경고·탈락·저장이 없습니다. 동작 줄이기 설정에서는 고정된 붉은 경고를 표시합니다.

## 기록

오늘의 단계별 기록을 기기·브라우저 localStorage에 저장하며 온라인 전송하지 않습니다. 게임 오버는 종료된 도전으로 기록하고 사용자 중단은 저장하지 않습니다. 이전 30초 기록은 삭제하지 않고 별도 저장 공간에서 새 기록을 시작합니다.

## 빛과 소리

내 전구가 켜진 동안 일정한 660Hz 삐 소리가 함께 납니다. 노트 자체가 자동으로 소리를 내지는 않습니다. 게임 상단의 소리 켜짐/꺼짐 버튼은 연습과 도전 중에도 표시됩니다. 기본은 켜짐이며 시작 또는 터치 후 소리를 사용할 수 있습니다. 손을 떼거나 도전을 중단하거나 화면을 벗어나면 소리가 멈춥니다. 외부 오디오 파일이나 인터넷 연결은 필요 없습니다.

## 인트로

처음에는 과학 원리 그림과 큰 게임 시작 버튼이 표시됩니다. 게임 시작을 누르면 단계 선택과 게임 화면으로 이동합니다. 게임 상단의 인트로 버튼으로 돌아가면 진행 중인 도전은 중단되고 소리가 멈추며 미완료 기록은 저장하지 않습니다.

게임 화면 진입 시 중앙 시작 준비 창에서 1~5단계를 선택하고 큰 60초 게임 시작 버튼으로 시작할 수 있습니다. 상단의 시작·단계 선택 버튼으로 다시 열 수 있습니다.

## 단계 통과

60초를 끝까지 완료하면 트로피와 해당 단계 통과 문구가 있는 성공 화면을 표시합니다. 1~4단계는 다음 단계 도전 버튼으로 바로 시작할 수 있고, 5단계는 최고 난도 성공 메시지를 표시합니다. 같은 단계 재도전과 기록 보기 기능도 유지합니다. 게임 오버에는 다음 단계 버튼이 나타나지 않습니다.

## 6·7단계 추가 (2026-10-15)

기존 1~5단계의 설정·신호 패턴·기록은 그대로 유지합니다.

- 6단계 섬광 연타: 102개 신호, 1.4초 미리 보기, 빠른 연속 전환
- 7단계 한계 돌파: 109개 신호, 1.1초 미리 보기, 최단 0.24초 신호와 불규칙한 쉼

60초 플레이 및 20초 이후 경고·게임 오버 기준은 동일합니다. 5단계 성공 후 6단계, 6단계 성공 후 7단계로 이어집니다. 최고 난도 성공 문구는 이제 7단계에 표시합니다. 시작 준비 창과 게임 화면 양쪽에서 1~7단계를 선택할 수 있습니다.

## 6·7단계 시각 효과

6단계는 청록색 배경과 전기 불꽃, 7단계는 보라·금빛 배경과 더 많은 입자·확장하는 빛 고리를 표시합니다. 입자는 성공 판정 시에만 생성하며 최대 90개로 제한합니다. 신호와 점수 규칙은 그대로입니다. 동작 줄이기 설정에서는 이동 배경·입자·확장 고리를 끄고 색상과 고정된 성공 표시를 유지합니다.
