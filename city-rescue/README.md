# 정전 도시 복구 작전

중학교 3학년 「전기 에너지는 다양하게 이용돼」 차시용 터치 게임입니다. 기존 ‘빛의 신호’와 별개로 실행됩니다.

## 실행

배포용 **energy-city.html** 하나를 브라우저로 여세요. SVG 그림, CSS, JavaScript가 모두 포함되어 설치·빌드·외부 이미지·네트워크 요청 없이 실행됩니다. Android에서 로컬 HTML 실행을 제한하는 파일 앱을 사용할 경우 정적 웹 호스팅에 올려 Chrome으로 접속하세요.

원본은 이 폴더의 index.html, style.css, core.js, app.js입니다. 개발용 단일 파일 갱신 명령은 상위 폴더에서 `node scripts/package-city.cjs`입니다. 학생은 Node가 필요하지 않습니다.

## 플레이

1. 인트로에서 1~3단계를 선택하고 시작합니다.
2. 요청을 읽고 지도 왼쪽 전원을 터치한 뒤 요청한 시설을 터치합니다.
3. 장치 하나와 그 임무에서 주로 이용할 에너지를 모두 선택합니다.
4. ‘장치 작동 · 전환 확인’을 누릅니다. 오답에는 설명이 제공되고 다시 선택할 수 있습니다.
5. 성공 시 시설에 효과가 나타납니다. 설명을 읽은 뒤 다음 요청을 받습니다.

1단계는 210초 및 연결 힌트, 2단계는 180초, 3단계는 135초입니다. 동일 단계에서 같은 임무 순서로 도전하므로 기록을 비교할 수 있습니다. 난이도는 시간 압박과 힌트 제공 여부로 나뉩니다.

## 차시 구성: 세 장, 아홉 임무

- 전달과 전환: 병원 조명, 안내 방송, 승강기 모터
- 다양한 전환과 목적: 보온 장치, 스마트폰 영상+음성, 전등에서 함께 발생한 열
- 저장과 재이용: 충전식 배터리 충전, 정전 시 비상등, 진동 알림

한 기기에서 여러 에너지 전환이 발생할 수 있음을 설명합니다. ‘주로 이용할 에너지’는 해당 임무의 목적을 기준으로 하며, 다른 형태의 에너지가 생기지 않는다는 뜻이 아닙니다. 조명에서 함께 발생한 열을 사라진 에너지라고 표현하지 않습니다.

배터리 충전은 전기 → 화학 에너지 저장, 사용은 화학 → 전기 → 필요한 에너지 전환으로 표시합니다. 배터리의 ‘비상 사용 2회’는 단순화한 게임 규칙으로 실제 용량이나 기기 소비량을 나타내지 않습니다. 복구 이력과 실제 현재 전원 공급은 구분하며 정전 시 시설의 밝기가 다시 꺼집니다.

## 시간·점수·기록

설명을 읽는 성공 피드백 화면과 일시정지 화면에서는 타이머가 멈춥니다. 탭을 벗어나도 자동 일시정지됩니다. 복귀 시 계속하기를 눌러야 진행됩니다.

- 임무당 1,000점, 최대 9,000점
- 오답당 150점 감점, 최저 0점
- 전부 해결하면 남은 시간 비율에 따라 최대 1,000점 추가
- 정확도 = 해결 수 / (해결 수 + 오답 수)

시간이 끝난 판도 해결한 임무의 점수로 기록합니다. 사용자가 중단한 판은 저장하지 않습니다. 기기 현지 날짜 기준 오늘의 단계별 최고 점수·도전 횟수·최근 10회 결과를 localStorage에 저장합니다. 서버로 전송하지 않습니다. 브라우저·주소가 다르면 기록도 분리됩니다. 저장이 막힌 경우 결과 화면에 안내합니다.

## 결과와 다음 차시

완료·시간 종료 시 에너지 전환 지도, 오답 관련 설명을 보여줍니다. 미해결 임무는 구분하여 표시합니다. 마지막에는 ‘같은 전기를 쓰는데 왜 배터리가 닳는 빠르기는 다를까?’라는 질문으로 다음 차시의 전력·사용 시간으로 연결합니다.
