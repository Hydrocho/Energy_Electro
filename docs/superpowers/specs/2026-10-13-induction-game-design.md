# 빛의 리듬 — 30초 발전 챌린지 설계

## 목적과 실행 환경
교과서의 전자기 유도를 학생이 직접 조작하며 익히는 짧은 게임이다. 학생들은 각자의 안드로이드 패드에서 터치로 플레이한다. HTML, CSS, 일반 JavaScript로 구현하며 빌드나 외부 라이브러리, 계정, 서버 데이터 저장을 요구하지 않는다. 정적 웹 주소에서 실행할 수 있고 파일 직접 열기도 지원 가능한 브라우저에서 동작한다.

## 학습 내용
- 자석과 코일의 상대적인 움직임으로 코일을 통과하는 자기장이 변할 때 유도 전류가 발생한다.
- 자석이 코일 안에 있어도 정지하면 전류는 발생하지 않는다.
- 같은 위치에서 움직임의 방향이 반대가 되면 유도 전류의 방향도 반대가 된다.
- 발전기는 운동을 통해 전기 에너지를 얻는 장치임을 결과 화면에서 설명한다.
- 같은 장치와 비슷한 위치에서 더 빠르게 움직일수록 자기 선속 변화율이 커져 전구가 더 밝아질 수 있음을 체험한다. 밝기는 속도만이 아니라 자석과 코일의 위치 관계에도 영향을 받는다.

## 한 판의 흐름
1. 시작 화면에서 상·중·하 난이도를 선택하고 해당 난이도의 오늘 최고 기록을 확인한다. 닉네임은 수집하지 않는다.
2. 시간 제한이 없는 짧은 연습에서 자석을 움직여 전구와 전류계의 반응을 확인할 수 있다.
3. 시작 버튼을 누르고 카운트다운 뒤 30초 동안 흘러오는 목표 밝기에 맞춰 자석을 코일 안팎으로 빠르게 또는 천천히 움직이거나 멈춘다.
4. 종료 시 난이도, 이번 점수, 정확도, 최대 콤보, 해당 난이도의 오늘 최고 점수, 도전 횟수, 최근 기록 최대 10개를 표시한다.
5. 다시 도전하거나 원리 설명을 볼 수 있다.

## 터치와 화면
패드 가로·세로 화면에 대응한다. 조작 영역은 충분히 크게 만들고 해당 영역 안에서만 페이지 스크롤을 방지한다. 자석 손잡이를 드래그하여 수평으로 움직인다. Pointer Events 및 pointer capture를 사용하며 손가락을 떼거나 터치가 취소되면 움직임을 멈춘다. 다중 터치는 첫 번째 포인터만 처리한다. 마우스와 방향키도 보조 입력으로 지원한다.

화면 상단에 남은 시간·점수·콤보를 표시하고, 그 아래에 오른쪽에서 왼쪽 판정선으로 흘러오는 목표 밝기 띠와 현재 밝기 커서를 배치한다. 띠 높이는 자석의 위치가 아니라 목표 전구 밝기임을 명시한다. 앞으로 4초의 패턴을 미리 보여준다. 중앙과 하단에는 목표 전구·내 전구, 자석·코일·전류계 및 넓은 터치 영역을 배치한다. 실제 조작은 자석을 좌우로 왕복시키는 것이며, 노트의 높이를 손가락 위치로 직접 맞추는 방식은 아니다.

현재 구간에 ‘천천히’, ‘빠르게’, ‘멈추기’ 안내를 표시한다. 외부 이미지와 교과서 스캔을 삽입하지 않고 SVG 또는 CSS 도형으로 실험 장치를 표현한다. 큰 글씨와 버튼, 색상 외의 방향 표시를 사용한다. 참고 게임의 흐르는 노트와 연속 판정에서 착안하되 캐릭터·그래픽·음악은 복제하지 않는다. 시작 터치 후 Web Audio로 간단한 박자와 판정음을 만들고 음소거를 제공한다. 소리 없이도 모든 조작과 판정이 가능하다.

## 난이도와 패턴
모든 난이도는 30초이며, 같은 난이도는 매번 동일한 패턴을 사용한다. 점수는 난이도별로 비교한다. 목표 밝기는 0~1로 정규화하고 난이도는 손가락의 과도한 속도보다는 전환 빈도와 판정 허용 폭으로 조절한다.

| 난이도 | 패턴 | 기본 구간 길이 | PERFECT / GOOD 허용 오차 |
| --- | --- | --- | --- |
| 하 | 꺼짐·약한 빛·밝은 빛의 세 단계, 단계별 충분한 유지 시간 | 3초 | 0.18 / 0.30 |
| 중 | 세 단계와 중간 밝기, 완만한 밝기 변화 | 1.5~3초 | 0.13 / 0.23 |
| 상 | 짧은 전환, 점점 밝게·어둡게, 짧은 정지 구간 | 0.75~1.5초 | 0.10 / 0.18 |

기준 박자는 분당 80박이다. 목표 밝기는 꺼짐 0, 약한 빛 0.25, 중간 빛 0.45, 밝은 빛 0.65를 기본으로 한다. 물리 모델을 대상으로 자동 왕복 입력을 검증하여 모든 목표가 실현 가능한 범위인지 확인하고, 필요하면 목표값을 조정한다.

## 점수와 공정성
점수는 발전량 합계가 아닌 목표 밝기와의 일치도이다. 빠르게만 움직이면 느린 구간에서 점수를 얻지 못한다. 구현은 자석이 코일에 부분적으로 들어가는 구간으로 이동 범위를 제한하고, 삽입량에 선형으로 비례하는 자기 선속의 시간 변화로 전류계 방향과 크기를 표현한다. 이 단순화 및 실제 장치의 위치 의존성은 원리 설명에 명시한다. 정지에는 전류가 발생하지 않는다. 전구 밝기는 전류 크기에서 계산하고 약 0.15초의 짧은 잔광을 적용하여 왕복 방향 전환 때 지나치게 깜박이지 않게 한다. 정지 시 전류는 즉시 0이 되고 밝기는 짧게 감쇠한다.

0.1초 간격으로 목표 밝기와 현재 밝기의 차이를 판정한다. PERFECT는 1, GOOD은 0.6, MISS는 0의 가중치를 부여한다. 최종 점수는 획득 가중치 합계를 전체 판정 수로 나눠 10,000점 만점으로 환산한다. 정확도는 PERFECT와 GOOD 판정 비율이다. 콤보는 연속 성공 판정 수이고 MISS에서 초기화하며, 별도 점수 배율은 없다. 정지 구간도 목표에 맞춰 멈췄으면 득점한다. 목표가 급격히 바뀌는 구간의 처음 0.2초는 직전 또는 새 목표 중 더 가까운 쪽으로 판정한다. 시작은 꺼짐 구간으로 통일한다.

입력 위치를 즉시 순간 이동시키지 않고 초당 최대 이동 속도를 제한한다. 경과 시간 기준으로 시뮬레이션하고 큰 프레임 간격은 제한하여 화면 크기, 터치 이벤트 횟수, 프레임 수로 과도한 이득을 얻지 않게 한다. 모든 학생이 같은 제한 시간과 점수 규칙으로 플레이한다. 화면에 표시한 최종 점수를 친구와 직접 비교한다. 온라인 순위표나 다른 학생의 기록 가져오기는 제공하지 않는다.

리듬 조작에 집중하기 위해 첫 버전에는 별도 퀴즈·랜덤 보너스·코일 이동 미션을 넣지 않는다. 앱이 숨겨지거나 브라우저가 백그라운드로 이동하면 진행 중 판은 중단하고 기록하지 않는다.

## 오늘 기록 저장
브라우저 localStorage에 버전, 기기의 현지 날짜(YYYY-MM-DD), 난이도별 완료한 판 수·최고 점수·최근 완료 기록 최대 10개를 저장한다. 각 기록에는 점수, 정확도, 최대 콤보, 완료 시간을 포함한다. 오늘은 기기의 현지 날짜를 기준으로 하며 UTC 날짜를 사용하지 않는다. 날짜가 달라지면 이전 날짜 데이터는 비우고 오늘 기록으로 교체한다. 화면 진입, 시작, 완료, 앱 복귀 때 날짜를 확인한다. 자정을 넘어 완료된 판은 완료 날짜에 저장한다.

저장 데이터는 읽을 때 형식과 수치 범위를 검사한다. 손상되었으면 초기화한다. 저장이 차단되거나 실패하면 메모리 내 기록으로 플레이를 계속하되 ‘이 브라우저에서는 기록을 저장할 수 없어요’라는 안내를 표시한다. 기록은 해당 기기와 브라우저에만 남으며 브라우저 데이터 삭제 시 사라진다는 점을 기록 영역에 짧게 알린다. 진행 중이거나 중단한 판은 저장하지 않는다.

## 파일 구성과 검증
- light-rhythm.html: 모든 코드와 스타일을 담은 단일 파일 배포본. 게임 실행에 빌드 불필요.
- index.html: 화면 구조와 접근성 요소.
- styles.css: 패드 반응형 레이아웃과 시각 표현.
- game.js: 상태 전환, 입력, 실험 장치와 노트 렌더링, 합성 박자와 판정음.
- engine.js: 물리 모델, 난이도별 패턴, 판정과 점수 계산.
- records.js: 데이터 검증과 날짜·난이도별 기록 저장.
- README.md: 실행 방법, 기록 범위, 수업 활용 안내.

점검 항목은 정지 시 무발전, 같은 위치에서 이동 방향 반전 시 전류 방향 반전, 입력 빈도와 무관한 이동 속도 제한, 목표 밝기의 도달 가능성, 판정 경계와 콤보, 난이도별 패턴 길이와 점수 상한, 30초 종료 후 점수 고정, 중복 저장 방지, 난이도별 기록 분리, 날짜 변경과 손상된 저장 데이터 처리, 저장 실패 시 게임 지속이다. 브라우저에서 시작·연습·완료·재도전·새로고침 기록 유지 흐름과 패드 화면 크기의 잘림 및 터치 조작, 음소거를 확인한다. 실제 안드로이드 기기에서 검증하지 못했다면 그 한계를 명시한다.
